# Web MVP Testing Checklist

- Signup with email and password.
- Login with the created account.
- Create a goal.
- View the goal list.
- Open a goal detail page.
- Submit a text check-in.
- Record a voice check-in.
- Confirm the audio is transcribed.
- Edit the transcript before submitting analysis.
- Generate daily analysis.
- View the daily result page.
- Confirm dashboard score, streak, active goals, latest insight, and tomorrow action.
- Generate a weekly report with fewer than 7 check-ins.
- Generate a weekly report with 7 or more check-ins.
- Open Settings.
- Delete all user data and confirm dashboard empty state.
- Logout.
- Confirm protected pages redirect when logged out.
